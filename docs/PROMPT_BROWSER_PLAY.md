# Приложение

- Название в Google Play: **Контроль ДЗ: уроки и телефон**
- Пакет: `kz.uroki.app`
- Разработчик: Oleg Ledovskoy, ИП «KonG Service», Казахстан
- Почта: urokikazakhstan@gmail.com · Сайт: https://urokiapp.kz
- Политика конфиденциальности: https://urokiapp.kz/privacy · Удаление аккаунта: https://urokiapp.kz/delete-account
- Что это: семейное приложение для школьной домашки и родительского контроля экранного времени (Android). Родитель
  ставит ребёнку задания, ребёнок отмечает их с фото; на телефоне ребёнка родитель может включить лимиты, время сна,
  школьные часы и «сначала уроки». Подписка 2990 ₸/мес, 7 дней бесплатно. Без рекламы.
