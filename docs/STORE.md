## Google Play

| Правило | Что требуется | Статус |
|---|---|---|
| Play Billing | Подписка через Google Play Billing | ✅ RevenueCat |
| Удаление аккаунта | В приложении **и** веб-страница без приложения | ✅ в приложении · ✅ `/legal/delete` · 🟡 указать URL в Play Console |
| Data safety | Анкета безопасности данных | 🟡 Личные данные: имя · Фото · Другой контент (задания, заметки) · Активность в приложении · Идентификаторы устройства (push-токен, ID покупателя) · Покупки. Цель — функциональность; не передаются для рекламы; шифрование при передаче — да; удаление по запросу — да |
| Политика конфиденциальности | URL в Play Console | ✅ `/legal/privacy` |
| Целевая аудитория / Families | Если приложение привлекательно для детей — соблюдать Families Policy | ⚠️ У ребёнка есть свой экран (серии, конфетти), поэтому **честно указать детские возрастные группы** вместе с 18+ и соблюдать Families Policy: рекламы нет, рекламный ID не собирается, сторонней аналитики нет, покупка только на телефоне родителя — всё это уже так |
| SCHEDULE_EXACT_ALARM | Точные напоминания | ✅ используется `SCHEDULE_EXACT_ALARM` (разрешение просим у пользователя, без него — неточные напоминания). Декларация Play нужна только для `USE_EXACT_ALARM`, который нам **не** подходит и не используется |
| Формат | AAB, подписанный upload-ключом | ✅ CI собирает `Uroki.aab`, когда заданы секреты ключа |
| Target API | Актуальный targetSdk | ✅ Expo SDK 57 |
